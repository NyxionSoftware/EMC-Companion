# Security Policy

## Reporting a vulnerability

Report vulnerabilities through GitHub private vulnerability reporting:

1. Open the Security tab of this repository.
2. Choose "Report a vulnerability".
3. Describe the problem and how to reproduce it.

Never open a public issue for a vulnerability.

## Supported versions

| Version | Supported |
|---|---|
| Latest release on `main` | Yes |

## What not to attach

Do not attach logs, exports, or screenshots that contain real enterprise data, credentials, or hostnames. This includes property names, employee names, server names, and object numbers from a real EMC installation. Reproduce the problem with the sample dataset instead.

See docs/PROJECT.md sections 2.5 and 13 for the project's sample-data and privacy rules.

## Scope

This policy covers the code in this repository. Report vulnerabilities in Oracle EMC itself to Oracle.
